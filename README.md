# excel-retail-analysis
Analysis of 541,909 transactions from a UK online gift retailer (Dec 2010 – Dec 2011) using Excel.

**Question:** Who are the most valuable customers and markets, and how do sales change through the year?

**Data:** [Online Retail dataset](https://archive.ics.uci.edu/dataset/352/online+retail), UCI Machine Learning Repository (CC BY 4.0).
